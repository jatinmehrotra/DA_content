# Demo 1 - Assessments (LIVE)

**What to show:** upload this inventory, let AWS Transform produce right-sizing + a TCO
business case, then generate the executive PPTX/PDF.

## Steps on stage
1. `aws login`
2. Open the AWS Transform console -> Assessments -> new assessment
3. Upload `server_inventory.csv`
4. Show: right-sizing recommendations, TCO comparison, and the generated exec deck/PDF

## The line
"Before you migrate anything, this answers: should I, and what will it cost - and it
builds the leadership deck for you."

10 servers, mixed Windows/RHEL, prod + dev. Small on purpose so it processes fast.
